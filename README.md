# BLOOD_DONATION_PREDICTION
Machine Learning project to predict repeat blood donation using donor history and compare classification models.




#### A Machine Learning project to predict whether a donor will donate blood in March 2007 based on their previous donation history.

📌 Project Highlights
Data Cleaning & EDA
Feature Analysis
Binary Classification
Logistic Regression
KNN
Random Forest
XGBoost
Hyperparameter Tuning using RandomizedSearchCV
Model Comparison using ROC-AUC

##### Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

🎯 Objective

To identify a suitable machine learning model for predicting repeat blood donations using historical donor information.
